# ab0t-events-go — v0.2 tickets ("Production-ready & interoperable")

Derived from `docs/PMM-REPORT_2026-08-12.md` §6 roadmap. Each ticket is
self-contained; see `WORKLOG.md` for execution notes and status.

Status legend: TODO · WIP · DONE

---

## EV-001 — Generalize the Signer port for pluggable schemes  · DONE
**Why:** the `Signer.Sign(secret, body)` shape can only sign the body; interop
schemes (Standard Webhooks) sign `id.timestamp.body` and own their own headers.
**Do:** change the port to `Sign(SigningInput) map[string]string`, where the
signer returns the auth headers to merge. Core sets the common idempotency
headers; the signer owns the signature/timestamp headers. Update hmacsign + all
wiring + tests + docs.
**Done when:** existing HMAC behavior preserved via the adapter; race-green.

## EV-002 — Standard Webhooks signing adapter  · DONE
**Why:** subscribers verify with off-the-shelf libraries in any language.
**Do:** `adapters/stdwebhook` implementing the new Signer with
`webhook-id` / `webhook-timestamp` / `webhook-signature: v1,<base64>` over
`{id}.{ts}.{body}`; ship a `Verify` helper. Unit-test the sign/verify round-trip
against the published test vector shape.
**Done when:** round-trip test passes; wired as an option in the facade.

## EV-003 — Startup recovery sweeper  · DONE
**Why (P0, ICE 27):** the in-memory queue loses queued retries on crash; the log
persists non-terminal deliveries, so re-enqueue them on boot.
**Do:** add `DeliveryFilter.Status`; add `Service.Recover(ctx, orgID) (int, error)`
that lists `pending`+`failed` deliveries, rebuilds each Job from the stored
snapshot + current subscription, and re-enqueues. Honor tenancy.
**Done when:** a test crashes/recreates a Service and Recover redelivers.

## EV-004 — Metrics observer adapter  · DONE
**Why:** every service shouldn't hand-roll counters.
**Do:** `adapters/metrics` — a dependency-free `Collector` implementing
`events.Observer`, tallying attempts by status/code + latency, exposing a
`Snapshot()`. Bridgeable to Prometheus/OTel by the consumer.
**Done when:** counts/latency verified by test.

## EV-005 — Auto-disable circuit breaker  · DONE
**Why:** stop hammering dead endpoints (Stripe behavior).
**Do:** `adapters/autodisable` — an `events.Observer` that counts consecutive
dead-letters per subscription (reset on delivered) and, at a threshold, pauses
the subscription via the store and fires an `OnDisable` hook. Add
`events.MultiObserver` to compose it with metrics.
**Done when:** threshold test disables the sub and fires the hook once.

## EV-006 — Admin HTTP API + delivery-log UI  · DONE
**Why:** the "seams"/user interface — services and support need to manage
subscriptions and inspect deliveries without rebuilding CRUD each time.
**Do:** `adapters/adminhttp` — a stdlib `http.Handler` (Go 1.22 mux) exposing
per-org subscription CRUD, secret rotation, delivery list/detail, and replay,
plus a minimal self-contained HTML delivery-log view. Org is taken from an
injectable auth func (never trust the client). JSON in/out.
**Done when:** handler tests cover CRUD + replay + tenancy + the HTML view.

## EV-008 — Honor Retry-After  · DONE
**Why:** best practice — respect a subscriber's 429/503 `Retry-After`.
**Do:** parse the header (seconds or HTTP date) in `httpdeliver` into
`DeliveryResponse.RetryAfter`; the core uses it as a lower bound on the next
backoff, capped by `MaxDelay`. **Done when:** parse + honor tests pass.

## EV-009 — Ping / send-test-event  · DONE
**Why:** let orgs verify an endpoint from the admin UI.
**Do:** `Service.Ping(ctx, orgID, subID)` delivers a synthetic `webhook.ping`
(bypassing the type filter); `POST /subscriptions/{id}/ping`. **Done when:**
delivers regardless of filter; cross-org denied.

## EV-010 — Stable User-Agent + benchmarks  · DONE
**Do:** send `httpdeliver.DefaultUserAgent` (overridable); add Emit/Process
benchmarks. **Done when:** UA test + benchmarks run.

## EV-012 — Per-destination rate limiting + contracts doc  · DONE
**Why:** PMM item 11 — protect slow subscribers and our egress. Plus: document
all seams/contracts (owner ask).
**Do:** `adapters/ratelimit` — a token-bucket `Deliverer` decorator keyed by host
(configurable), injectable clock, blocks up to the ctx deadline. Write
`docs/CONTRACTS.md` covering every port's contract (caller, concurrency, tenancy,
errors, implementers). **Done when:** deterministic bucket tests + throttle/cancel
tests pass; contracts doc covers all seams.

## EV-011 — Durable SQS queue (v0.3 flagship)  · DONE
**Why:** the in-process queue loses jobs on crash; production needs durability.
**Do:** reusable core primitives — `JobRef`, `Job.Ref()`, `Rehydrator`,
`RefDispatcher`, `Service.Rehydrate`/`ProcessRef` — so ANY off-process queue
carries id-only refs and rehydrates from store+log (secrets never queued). Ship
`adapters/sqsqueue` as the reference: bring-your-own SQS client interface, delay
mapping, re-defer for long backoffs, at-least-once (drop terminal/missing refs).
**Done when:** unit tests (fake SQS) + an end-to-end test through a real Service
prove id-only messages and rehydrated delivery; race-green.

## EV-007 — Secret rotation  · DONE
**Why:** rotate a leaked/aging secret without deleting the subscription.
**Do:** `Service.RotateSecret(ctx, orgID, subID) (newSecret string, err error)`
generating a fresh secret and persisting it; expose via the admin API.
**Done when:** rotation test changes the signing secret; tenancy enforced.
